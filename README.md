# grammar-kb-web · 语法知识库学习地图

grammar-kb 题库 API 的只读学习前端，面向学生按 **课程 / 知识点 / 关系网络** 三种方式浏览英语语法讲义。

## 功能

- **按课程浏览**：48 讲按语法体系（词法 / 时态 / 语态 / 非谓语 / 句法 / 综合复习）分组，点开看整讲内容。
- **词汇表**：基于后端 `/vocabulary`（讲义中英对照例句自动提取），600+ 高频词，支持按词性筛选、搜索单词/释义、按词频或字母排序；点开单词看释义、词形变化（时态/比较级等）与讲义出处，出处可直接跳到对应知识点。
- **🎯 考点信号（双向）**：每个知识点详情里按时态分组列出标志词，点任一时态 / 标志词即可**反向**列出所有考它的知识点——「看到这个词/时态，就是在考哪些知识点」，反之亦然，形成知识点 ↔ 标志词/时态的双向跳转。
- **同讲连边** —— 同一课程内的知识点（讲义结构）
  - **同主题标签** —— 共享细分标签（跨讲的主题簇）
  - **同时态标志词** —— 共享标志词时态（跨讲的时态脉络）

> 后端 `relations` 字段目前不带显式连线目标，因此关系网络的连线由前端基于知识点的共享属性推断。如需精确的显式关系，可在后端补全 `to_kp_id` 后切换为直连模式。

## 数据后端

依赖本地运行的 grammar-kb 服务（默认 `http://127.0.0.1:8000`）。开发期由 Vite 把 `/api/*` 代理到该地址；生产部署需用反向代理承担同样的转发。

## 开发

```bash
npm install
npm run dev      # 打开 http://localhost:5180
npm run build    # 产出 dist/
npm run preview  # 预览构建产物
```

## 技术栈

Vite + 原生 ES Modules · ECharts（力导向图）· marked（Markdown 渲染）。无框架依赖。

## 已知限制

- 后端无「列出全部知识点」端点，前端用一组高频检索词聚合去重取回知识点（当前覆盖约九成，余下多为纯英文表格/极简条目）；后端补一个 `/kp` 列表端点即可取全。
- 知识点在首次访问时批量检索并缓存于 `localStorage`（按知识点总数版本化，数据更新后自动失效重取）。
